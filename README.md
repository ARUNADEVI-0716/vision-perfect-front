# Pixel Perfect Clone

Recreate the attached webpage screenshot as closely as possible, pixel-perfect.

Match exactly:

- Overall layout and section order

- Color palette (pick exact colors from the image)

- Typography (font family, weights, sizes, line height)

- Spacing, padding, margins, border radius, shadows

- Icons, buttons, cards, images, and all visible text

Rules:

- Single page, keep the desktop view identical to the screenshot, then make it responsive.

- Use only local/self-contained assets. Use inline SVG icons (lucide-react is fine) and avoid external image URLs that could break; use similar placeholder visuals where needed.

- Add hover states, transitions, and any interactive behavior the design suggests (menus, tabs, carousel, accordions).

- No backend, no login, no database, no Supabase or authentication. Frontend only.

- Keep the project simple with minimal dependencies so it runs after "npm install && npm run dev".

- Do not add extra sections or content not in the screenshot.

Build the whole page in one go, then I will give corrections. Add extra functionality too , that also counts for mark.
